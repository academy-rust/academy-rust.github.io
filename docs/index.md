**🚀 为什么选择 Rust？**  

Rust 与 C/C++ 同为系统编程语言。因其在设计上融入了现代语言特性，被学术界和工业界公认具备更优的内存安全性与可靠性。更重要的是，凭借这一安全性优势，Rust 是 AI 时代最佳的系统编程语言。
