# Rust 与数据库

<div class="rust-callout" markdown="1">
**🗄️ 数据库系统开发**

探索 Rust 在数据库系统中的应用，学习如何构建高性能、可靠的数据存储系统。
</div>

## Rust 数据库项目

- [TiKV](https://github.com/tikv/tikv) — 分布式事务键值数据库
- [Databend](https://github.com/datafuselabs/databend) — 云原生数据仓库
- [SurrealDB](https://github.com/surrealdb/surrealdb) — 多模型数据库

## 学习资料

- [CMU 15-445 Database Systems](https://15445.courses.cs.cmu.edu/) — 经典数据库课程
- [Database Internals](https://www.databass.dev/) — 数据库内部实现

## Rust 数据库库

- [diesel](https://diesel.rs/) — 安全、可扩展的 ORM 框架
- [sqlx](https://github.com/launchbadge/sqlx) — 异步 SQL 工具包
- [sea-orm](https://www.sea-ql.org/SeaORM/) — 异步 ORM 框架
