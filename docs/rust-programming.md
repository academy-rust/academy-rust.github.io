# Rust 编程语言

<div class="rust-callout" markdown="1">
**📖 学习路径**

从零开始学习 Rust 编程语言，掌握系统编程的现代化方法。本页汇集了官方教程、经典教材与实践课程。
</div>

## 官方教程

### The Rust Programming Language (The Book)
[The Book](https://doc.rust-lang.org/book/)  
Rust 官方权威教程，全面系统地介绍 Rust 语言特性与编程范式，适合初学者入门。

### Rustlings
[rustlings](https://rustlings.rust-lang.org/)  
通过大量小练习学习 Rust 语法与核心概念，边练边学，巩固理解。

## 推荐课程

- [Rust 语言圣经](https://course.rs/) — 优质的中文 Rust 教程
- [Rust by Example](https://doc.rust-lang.org/rust-by-example/) — 通过示例学习 Rust
