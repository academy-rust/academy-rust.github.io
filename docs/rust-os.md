# Rust 与操作系统

<div class="rust-callout" markdown="1">
**💻 系统编程实践**

使用 Rust 开发操作系统内核，体验内存安全的系统级编程。本页汇集了清华大学等知名高校的 OS 课程资源。
</div>

## 推荐课程

### 清华大学 — rCore-Tutorial

[课件](https://learningos.cn/os-lectures/)  
[项目仓库](https://github.com/LearningOS/os-lectures)  
[开放训练营](https://opencamp.cn/os2edu/camp/2026spring)

清华大学基于 Rust 的操作系统课程，从零开始构建完整的 OS 内核。课程内容涵盖：

- RISC-V 架构基础
- 内存管理
- 进程管理
- 文件系统
- 并发与同步

## 推荐教程

### Writing an OS in Rust
[Writing an OS in Rust](https://os.phil-opp.com/) — 国际知名的 Rust OS 教程

详细的博客系列，一步步教你用 Rust 编写一个小型操作系统：

- 启动流程
- VGA 文本模式
- CPU 异常处理
- 内存管理（分页系统）
